What this demonstrates

  • FNV-1a 64-bit hash — same as substrate canon, byte-exact across all 7 locales
  • Witness-log — every state change is hash-chained, verifiable
  • JEV scoring — cosine similarity across cells, top-5 retrieval
  • Wavefunction JEV — explicit interference across cells with phase from cluster hash
  • In-browser training — real gradient descent on linreg and MLP
  • PDE solver — Burgers' 1D with upwind advection + diffusion
  • SAT solver — Pigeonhole with at-most-one + at-least-one constraints
  • IndexedDB — substrate state survives browser refresh
  • 3D visualization — cell-graph rendered on canvas
  • WebGPU compute — same primitives, on your GPU
  • WebNN — direct neural network ops with hardware acceleration
  • Distributed — train on your hardware, submit to Quilt Cloud
  • IoT — substrate as network of devices
  • Multiplayer — Casey + playtesters in shared session
  • Truman Garden — send any AI chatbot to fill canon gaps
  • Cross-AI — DeepSeek, Kimi, Z.AI, Grok all become cells
