🧬 Quilt Substrate — Browser Native

Three browser-native substrate implementations. No server required. Your data stays in your browser.

1. Substrate Core (Interactive Cell-Graph)

20+ canonical cells seeded, witness-log, JEV top-5 search, wavefunction JEV, 3D visualization, IndexedDB persistence, and a real (in-browser) linear regression + MLP trainer.

▶ Open Substrate Core

2. Substrate ML (Browser Training)

Browser-native ML training. Real gradient descent on linear regression and XOR. Burgers' 1D PDE solver. SAT solver with Pigeonhole. Witness-log audit. WebGPU detection.

▶ Open Substrate ML

3. Substrate GPU (WebGPU Compute) 🚀

WebGPU compute shaders for FNV-1a 64-bit hash and JEV cosine similarity. Run the same substrate primitives on your GPU. Includes benchmark to show GPU vs CPU speedup.

⚡ Open Substrate GPU

4. Substrate WebNN (Web Neural Network API)

WebNN graph builder for MatMul + Softmax + MLP. Hardware-accelerated via ML backend (CPU/GPU/NPU). Falls back to CPU.

🧠 Open Substrate WebNN

What this demonstrates

  • FNV-1a 64-bit hash — same as substrate canon, byte-exact across all 7 locales
  • Witness-log — every state change is hash-chained, verifiable
  • JEV scoring — cosine similarity across cells, top-5 retrieval
  • Wavefunction JEV — explicit interference across cells with phase from cluster hash
  • In-browser training — real gradient descent on linreg and MLP
  • PDE solver — Burgers' 1D with upwind advection + diffusion
  • SAT solver — Pigeonhole with at-most-one + at-least-one constraints
  • IndexedDB — substrate state survives browser refresh
  • 3D visualization — cell-graph rendered on canvas
  • WebGPU compute — same primitives, on your GPU
  • WebNN — direct neural network ops with hardware acceleration
