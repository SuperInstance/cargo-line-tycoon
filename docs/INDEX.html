What is this?

cargo-line-tycoon is a polyformal (many-languages, many-locales) game where every operation is an opcode in a canonical 11-opcode algebra, every state change is hash-chained in a witness-log, and every locale teaches the same cell-graph through its own pedagogical lens.

The substrate defends against memory-poisoning attacks at both layers (storage witness-log + execution Memory Sandbox), and beats FluctlightDB's 18% provenance-conflict with 100% top-1 accuracy under shared-brain conditions.
